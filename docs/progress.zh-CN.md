## 当前阶段

**M0：单个视觉 Agent 的最小游玩闭环已打通。**

```text
当前游戏截图 → DeepSeek Harness 看图选键 → 输入校验

```

## 已解决的问题

1. **首帧空棋盘**：模型实测发现 2048 方块入场动画尚未显示。该游戏的截图配置现在显式完成有限 CSS 动画；已核查其脚本不依赖 animationend/transitionend。
2. **持续按住不等于重复点击**：一次方向键选择展开成明确的按下和松开，避免同键连续选择不产生新按键事件。
3. **重放不等于验证**：没有内部探针时只报告输入已重放，不报告已验证复现；版本或检查点不一致时报告偏差。
4. **模型读取失败不能假装继续**：只有成功读取当前截图并返回合法按键才执行操作，异常结束本轮并留下失败记录。

## 当前限制

- 每次决策启动一个新的 Harness headless 进程，只有显式传入的短历史；没有持久 SDK 会话或长程计划。
- 已实现的 Harness 策略是 2048 专用短按策略；尚未支持持续动作的模型决策和通用任务描述。
- 浏览器虚拟时间不是引擎物理帧保证；CSS、worker、网络和音频需要逐游戏核查。
- PRNG 复现依赖显式 Math.random 测试替换，不能推广为任意游戏的确定性。
- 截图动画完成配置只针对已验证的 2048；实时游戏需单独设计。
- 检查点匹配只覆盖探针读取的字段；尚无通用漏洞规则、Fuzz 搜索、步骤缩减或控制台。
- Godot 桥接与 Rest-in-Pieces 接入尚未实现，其他候选游戏尚未运行接入。
